## 什么是 Clash Verge？

Clash Verge 是一款基于 Clash 核心构建的现代化、功能强大的网络代理管理工具，旨在为 Windows 和 macOS 用户提供一个直观、易用的图形界面。它将复杂的 Clash 配置过程转化为简单明了的操作，让用户无需深入理解命令行，也能轻松驾驭各种网络代理需求。作为一款免费且开源的软件，Clash Verge 不仅继承了 Clash 引擎的高性能和灵活性，更通过精美的用户界面和丰富的功能，显著提升了用户体验，是当前市场上备受推崇的网络代理客户端之一。

## Clash Verge 的核心功能与亮点

Clash Verge 在其简洁的外表下，蕴藏着诸多实用且强大的功能，使其成为众多用户的首选。这些功能协同工作，为用户带来了流畅且可控的网络代理体验：

*   **直观的配置文件管理：** 用户可以轻松地通过订阅链接或本地文件导入、管理和切换不同的 Clash 配置文件。界面会清晰展示所有可用配置，并允许用户进行基本的编辑和更新操作，满足个性化需求。
*   **便捷的代理模式切换：** 支持全局代理、规则代理（Rule-based Proxy）和直连（Direct）等多种代理模式的一键切换，用户可以根据当前网络环境和使用场景灵活选择，实现精细化的流量控制，确保既能访问受限内容，又不影响本地服务的正常使用。
*   **实时的节点管理与测试：** Clash Verge 提供清晰的节点列表，并支持对所有代理节点进行实时延迟测试，帮助用户选择速度最快、最稳定的连接，确保流畅的网络体验。用户还可以根据需要对节点进行排序和筛选。
*   **详细的连接日志与流量统计：** 用户可以实时查看通过 Clash Verge 代理的所有网络连接日志，以及详细的上传/下载流量统计，全面掌握网络使用情况，对于排查问题或监控流量消耗都非常有帮助。
*   **现代化与响应式用户界面：** 采用最新的 UI/UX 设计理念，界面美观大方，操作逻辑清晰，无论是新手还是资深用户都能快速上手。同时，界面设计考虑了不同分辨率的屏幕，提供了良好的用户体验。

## 如何开始使用 Clash Verge？

开始使用 Clash Verge 的旅程非常简单，只需几个步骤即可完成设置并畅享便捷的网络代理服务。以下是您迈出第一步的详细指南：

1.  **获取与安装：** 首先，您可以前往 Clash Verge 的官方发布页面，下载适用于您操作系统的最新版本安装包（例如，Windows 版的 `.exe` 文件或 macOS 版的 `.dmg` 文件）。下载完成后，双击安装包，并按照屏幕上的提示完成安装过程。整个过程通常十分迅速且无需复杂配置。
2.  **导入配置文件：** 安装完毕后，启动 Clash Verge。您可以通过两种主要方式导入代理配置文件：
    *   **订阅链接：** 这是最常用的方式。将您的代理服务提供商提供的订阅链接粘贴到“订阅”或“配置”部分的相应位置，点击下载按钮即可自动获取并更新配置。Clash Verge 支持自动定期更新订阅，确保您始终拥有最新的节点信息。
    *   **本地文件：** 如果您有存储在本地的 Clash 配置文件（通常是 `.yaml` 或 `.yml` 格式），也可以直接从本地文件导入使用。在“配置”界面选择导入本地文件选项，然后选择您的配置文件。
3.  **选择节点与模式：** 成功导入配置文件后，Clash Verge 会解析并展示所有可用的代理节点。在“代理”或“节点”界面，您可以根据延迟测试结果或个人偏好选择一个您想使用的代理节点。接着，在“模式”选项中选择适合您的代理模式，例如“规则”模式以获得更智能的流量分发，或“全局”模式使所有流量通过代理。
4.  **开启系统代理：** 最后一步，也是关键一步，点击主界面上的“系统代理”开关，使其处于开启状态。此时，Clash Verge 将接管您的系统网络请求，所有符合规则的流量都将通过您选择的代理节点进行传输。现在，您就可以开始体验稳定、高效的网络代理服务了。
