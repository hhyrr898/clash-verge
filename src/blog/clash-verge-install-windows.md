## 写在前面

上周有位读者在评论区问我：装完 Clash Verge Rev 之后点了好几次图标都没反应，是不是装坏了？我让他把版本号和安装路径发过来，发现他用的是 2.3.2 之前的旧包，又是在带中文空格的目录里解压运行，问题基本就出在这两处。这篇就把 Windows 端从下载到首次启动的完整流程写清楚，版本以 2024 年 11 月发布的 Clash Verge Rev v2.1.2 为例，你按自己的实际版本对照着看即可。

先说明一个前提：Clash Verge Rev 使用的是 mihomo（原 Clash.Meta）内核，不是老版 Clash 内核。这一点会直接影响后面订阅格式和 TUN 模式的判断，想先补背景的可以看[这篇内核说明](/blog/clash-verge-mihomo-kernel/)。

## 一、下载前的两个确认

### 确认系统架构

按 Win + Pause 打开系统信息，看「系统类型」是 64 位还是 ARM64。绝大多数人下 x64 的安装包，Surface 等 ARM 设备要选 arm64 版本，装错了会出现启动即闪退。

### 确认安装包来源

只从项目 Release 页面拿 exe 或 msi，不要用来路不明的「绿色版」。文件名里带 `x64-setup` 的是安装版，带 `portable` 的是便携版。我第一次装的时候图省事用了便携版，结果每次换目录都要重新配 TUN 服务，后来换回安装版省心不少。

## 二、四步完成安装

1. **运行安装包**。双击 msi，Windows 会弹 SmartScreen 提示，点「更多信息」再点「仍要运行」。安装路径建议保持默认，别放在中文或带空格的目录下。
2. **选择安装范围**。弹窗里选「仅为我安装」即可，避免后续写系统服务时权限混乱。
3. **等待安装完成并首次启动**。装完后桌面会出现图标，第一次启动会初始化配置目录，稍等几秒进入主界面。
4. **安装 TUN 系统服务**。进入「设置」页，找到 TUN 模式相关开关，点击安装服务，系统会弹 UAC 授权框，点「是」。这一步不做，TUN 模式打不开。详细说明可以参考 [TUN 模式配置指南](/blog/clash-verge-tun-mode-guide/)。

第 4 步是新手最容易漏的。TUN 模式不是软件内部开关，它依赖一个后台系统服务来接管虚拟网卡，服务没装，开关拨过去也会自动弹回来。

## 三、首次启动后要做的三件事

### 导入订阅

在「配置」页粘贴订阅链接，点导入。导入后留意节点列表是否正常刷新，如果一直转圈，多半是订阅链接本身或时间同步的问题，可对照[订阅更新失败排查](/blog/clash-verge-subscription-update-fix/)逐项检查。

### 看一眼内核状态

主界面底部或设置页会显示当前内核版本，确认后缀是 mihomo。如果显示的是旧内核名，说明你装的不是 Rev 版本，建议重装。

### 打开面板确认连通

切到「代理」页选一个节点，再打开系统代理开关，然后浏览器访问一个常用站点验证。想更系统地验证，可以按[浏览器连通性检查](/blog/clash-verge-browser-check/)里的方法走一遍。

我自己习惯装完先把配置备份一次，导出到本地，后面折腾坏了直接还原。备份的具体位置和导出方式见[配置备份教程](/blog/clash-verge-backup-config/)，这步花不了两分钟，但能省很多事。

## 常见问题

### Q1：双击图标没反应，任务管理器里也没有进程？

先确认安装路径没有中文和空格，再检查是不是被杀毒软件拦截了。部分安全软件会把安装服务那一步的可执行文件当可疑程序处理，加白名单后重装一次通常就好了。

### Q2：TUN 模式开关拨过去又弹回来？

基本就是系统服务没装成功。回到设置页重新点安装服务，看 UAC 是否被取消；如果反复失败，先卸载服务再重装，具体处理方式在 TUN 那篇里有写。

### Q3：导入订阅后节点为空？

检查订阅链接是否过期，以及系统时间是否准确。mihomo 内核校验对时间偏差比较敏感，时间差太多会直接拉取失败。

### Q4：能上网但部分应用不走代理？

系统代理只对遵守代理设置的程序生效，游戏、部分客户端需要 TUN 模式接管。确认服务已装、TUN 已开，再观察是否恢复正常。

## 最后提醒

装完之后如果打算长期用，建议把桌面快捷方式和开机自启按自己的习惯调一下，参考[快捷方式设置](/blog/clash-verge-desktop-shortcuts/)。另外，真要从头卸载重装，别只删图标，按[干净卸载流程](/blog/clash-verge-clean-uninstall/)走，否则残留的服务会影响下一次安装。整个过程不复杂，关键是别跳过装服务那一步。
